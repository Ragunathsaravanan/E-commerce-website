🛒 E-Commerce Web Application

A dynamic and responsive E-commerce platform built with Django, Python, and SQLite/MySQL.
This project allows users to browse products, filter by categories, place orders, and manage accounts, while admins can add/manage products and monitor orders through a secure dashboard.

🚀 Features
User Side

🔑 User Authentication (Sign-up/Login) with secure password hashing

🛍️ Product Catalog with categories and search

📦 Product Detail View with stock availability

🛒 Shopping Cart & Order Placement with automatic stock updates

📱 Responsive UI for smooth shopping experience

Admin Side

🛠️ Admin Dashboard with role-based access control

➕ Add, update, and delete products

📊 Manage stock and pricing

👨‍💼 Staff access with limited permissions

🛠️ Tech Stack

Backend: Django (Python)

Database: SQLite / MySQL

Frontend: HTML5, CSS3

Authentication: Django sessions & hashed passwords
